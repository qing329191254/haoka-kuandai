# 派客邦功能打通清单

更新日期：2026-08-31

## 已形成闭环

### 代理 App

- 手机号密码 / 验证码登录、忘记密码、账号停用校验。
- 代理入驻申请、合同签署状态、押金状态、后台审批、审批通过后下单权限。
- 后台上架套餐与佣金、商家覆盖范围同步到 App；服务端按真实套餐重新计算订单名称、运营商和佣金，拒绝客户端篡改。
- 号卡、合约机、宽带、WIFI、CPE、存量业务下单和订单查询。
- 客服热线、FAQ、快捷回复、用户协议、隐私政策、帮助内容均读取后台配置，离线时使用内置内容兜底。
- 个人资料修改和意见反馈提交，后台可查看并标记处理。

### 商家 / 师傅小程序

- 商家申请、后台审核、审核状态查询；商家与师傅按身份登录。
- 商家接单、远程办结、跟进、恢复办理、标记上门、派单、电脑端开户、确认装机、取消订单。
- 商家新增、编辑、停用、删除本门店师傅。
- 师傅接单、手机端开户、交付成功、交回商家跟进。
- 交付照片会先上传到服务端再完成订单，不再保存微信本机临时路径。
- 订单详情与派单均按门店 / 师傅归属校验，不能跨门店查看或派单。
- API 地址可通过 `VITE_API_BASE` 区分开发与生产环境。

### 运营后台

- 代理 / 商家入驻审批，代理、商家、师傅、App 用户档案维护。
- 全量订单查询、详情、备注与取消。
- 商品套餐、存量业务类型、仓库档案、手工出入库与库存预警。
- FAQ、客服配置、反馈处理、协议与帮助内容维护，并同步到 App。
- 后台角色和账号的新增、编辑、删除已真正落库；角色占用、超级管理员和当前账号删除均有保护。
- 仓库编辑不会再重复新增；库存只能通过正数出入库单调整。
- 生产构建不要设置 `VITE_API_BASE`；把 `admin/dist` 复制到 `server/admin_dist`，由 FastAPI 同源托管页面和 `/api`。

## 暂缓：需要第三方服务或生产资质

- 短信：阿里云 / 腾讯云短信模板、签名、频控、防刷和发送回执。
- 电子签：e签宝 / 法大大实名、签署链接、回调验签、合同 PDF 归档与下载。
- 支付：微信 / 支付宝下单、异步回调验签、退款、对账和异常订单补偿。
- 运营商 BOSS：开户、装机工单、办理结果目前由商家 / 师傅手工确认，后续接运营商接口后自动回写。
- 消息通知：微信订阅消息、App 推送、审核结果和订单状态变更提醒。
- 对象存储：当前交付照片落在 `server/uploads`，生产需迁移到 OSS / COS，并改为私有桶和有时效的访问 URL。

## 下一阶段建议优先补

1. App 入驻证件和自定义头像目前仍是设备本地文件路径；应接私有文件上传、后台预览、权限控制和删除策略。
2. “在线客服”目前是 FAQ 自动回复，没有客服坐席会话、未读数、转人工与消息留痕。
3. 号卡实物库存目前是人工出入库，没有在接单 / 完成 / 取消时自动预占、扣减和释放。
4. 增加数据库迁移工具（如 Alembic）、生产密钥管理、上传文件备份与定时清理。
5. 增加完整端到端自动化：代理下单 → 商家接单 → 派单 → 师傅交付 → 后台核查。
