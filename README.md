# 派客邦

号卡 / 宽带业务三端协同系统。

## 角色划分（重要）

| 端 | 角色 | 职责 |
|----|------|------|
| **App** | 代理（统一入驻身份） | 申请入驻 → 后台审核通过后，提交号卡 / 宽带订单；宽带可选省市区并**指定本地商家** |
| **小程序** | 本地商家 / 上门师傅 | 商家申请入驻 → 审核通过后：订单录入 → 订单办理 → 派单上门；师傅上门履约 |
| **后台** | 运营 | 代理 / 商家入驻审批、档案、全量订单与配置 |

不对普通 C 端用户开放自助办卡。App 无本机号一键登录，使用手机号 + 密码；未通过审核不可下单。

## 目录

| 目录 | 端 | 技术栈 |
|------|----|--------|
| `app/` | 代理 App | Flutter（Android + iOS） |
| `admin/` | 运营后台 | Vue3 + Element Plus + Vite |
| `mp/` | 本地商家 / 上门师傅小程序 | UniApp（Vue3 + Vite） |
| `server/` | 三端统一后端 | FastAPI + MySQL（Redis 可选） |

### 1. 号卡

`订单录入` → `订单办理` → `派单上门` → `师傅上门开户激活` → `完成`

上门未成功的订单回到 **订单办理 · 跟进中**。

### 2. 宽带（需新开卡）

`订单录入` → `订单办理` → `派单上门` → `师傅 BOSS 手机端开户` → `装机` → `完成`

### 3. 宽带（无需新开卡）

`订单录入` → `订单办理（商家电脑端开户）` → `装机` → `完成`

## 本地启动

先起数据库，再起后端，最后开三端。本机若已有 MySQL 占用 `3306`，本仓库的 Docker 映射到 **3310**。Redis 用于短信验证码 5 分钟 TTL；连不上时仍可用演示码 `123456`。JWT 无状态，登录会话不依赖 Redis。

```bash
# 1) MySQL（库名 paikebang / 用户 paikebang / 密码 paikebang123）
docker compose up -d mysql

# 2) 后端
cd server
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

接口文档：<http://127.0.0.1:8000/docs>。健康检查：<http://127.0.0.1:8000/health>。

演示账号与各端一致（密码均为 `123456`，短信验证码 `123456`）：

| App | `13800138000` |
| 小程序商家 | `13800001001` |
| 小程序师傅 | `13600001111` |

短信、支付、电子签目前为适配层占位（`server/app/integrations.py`），后续再接真实通道。师傅交付照片已先使用服务端本地存储打通，生产环境再切换到带私有访问控制的对象存储。

### App（Flutter）

```bash
cd app
flutter pub get
flutter run
```

默认请求 `http://127.0.0.1:8000`（Android 模拟器为 `http://10.0.2.2:8000`）。真机请用 `--dart-define=API_BASE=http://电脑局域网IP:8000`。底部导航：首页提交业务 → 订单 → 客服 → 我的。

### 运营后台

```bash
cd admin
npm install
npm run dev
```

演示登录：`admin` / `123456`（另有 finance、service）。开发环境默认请求 `http://127.0.0.1:8000`。

生产把打包后的 `admin/dist` 交给 FastAPI 同源托管（不要把 Vue 源码拷到服务器，也不要设置 `VITE_API_BASE`，页面会请求同源 `/api`）：

```bash
cd admin
npm run build
cd ../server
python copy_admin.py
```

Windows 云主机用 `run_prod.bat` / `setup_prod.ps1`（监听 `0.0.0.0:8888`，不要加 `--workers`）。天翼云未备案时 80/8080 常被拦截，继续用现网的 **8888**。先停掉占用 8888 的 IIS 静态站。`.env` 中设置 `PUBLIC_BASE_URL=http://公网IP:8888`。健康检查里 `admin: true` 表示前端已拷入 `server/admin_dist`。

### 小程序（微信）

```bash
cd mp
npm install
npm run dev:mp-weixin
```

用微信开发者工具打开 `mp/dist/dev/mp-weixin`，并勾选 **不校验合法域名**。登录页可选「商家入驻申请」；已通过商家可在工作台管理「上门师傅」。

生产构建前复制 `mp/.env.example` 为相应环境配置，并将 `VITE_API_BASE` 改为已备案、已加入微信小程序服务器域名白名单的 HTTPS API 地址。
